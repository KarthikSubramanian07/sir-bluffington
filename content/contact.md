# Contact Sir Bluffington's Poker

> The best way to reach the people behind Sir Bluffington's Poker is a GitHub issue. Bug reports, feature ideas, questions about the bots, and press enquiries are all welcome.

## Report a bug or request a feature

Open an issue on the project's GitHub repository: [github.com/KarthikSubramanian07/sir-bluffington/issues](https://github.com/KarthikSubramanian07/sir-bluffington/issues). Issues are public, so please do not include anything private.

A useful bug report includes what you did, what you expected to happen, and what happened instead. For a hand that played out wrongly (for example, a side pot that looks incorrect), include the table size, the stacks, and the actions in order. The post-hand review screen shows the pot breakdown you can copy from. Mention your browser and device too.

## Questions about the game

Questions about how a bot plays, how equity is calculated, or why a pot was split a certain way are welcome as issues as well. The answers often turn into documentation. The [About page](https://sirbluffington.pages.dev/about) and the project's design notes on GitHub cover most of how the game works.

## Security

If you find a security problem, please open a GitHub issue that says you have a security report without sharing the details, and the maintainers will arrange a private channel.

## Where we are

Sir Bluffington's Poker is made in Berkeley, California, United States. The project has no office or phone line; GitHub issues are the way to get in touch.

## Response times

This is a free, volunteer-maintained project. Issues are usually read within a few days. There is no paid support, and there are no accounts, so there is never anything to recover or refund.
